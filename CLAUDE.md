# Jellyfin TV

Remote-first PySide6/QML Jellyfin frontend for Linux TVs and HTPCs, in `jellyfin_tv/` + `packaging/`. Playback runs in an external mpv.

## Rules
- No comments in code. Brief explanations. Match surrounding style.
- Commit checkpoints on `master` and push to `origin`.
- Tests must pass before anything deploys; add tests with new logic.
- Verify UI changes with the offscreen harness (below), not by opening windows on the user's desktop.

## Run / test
- Dev: `.venv/bin/python -m jellyfin_tv --windowed` (venv uses system PySide6 via --system-site-packages; deps in `packaging/requirements.txt`).
- Tests: `QT_QPA_PLATFORM=offscreen .venv/bin/python -m unittest discover -s jellyfin_tv/tests -t .` plus `.venv/bin/python -m pyflakes jellyfin_tv`.
- Harness pattern: QT_QPA_PLATFORM=offscreen, register types via `AppController.register_types()`, drive keys with QKeyEvent on the window, `win.grabWindow().save()`, call `openItem` via QMetaObject.invokeMethod. Headless playback: set setting `mpv_extra` to `vo=null\nao=null\nfullscreen=no`.
- Test server: Remux (Jellyfin 10.11 API) http://serv.local:3020, user `testuser` / `test`.

## Architecture
- `api/`: `client.py` (own `ApiClient` over requests: `{UserId}` filled in path/params/json, `playback_info`), `session.py` (connect via `System/Info/Public` following redirects, `Users/AuthenticateByName`, token in keyring, 0600 file fallback), `library.py` (all endpoints, DEVICE_PROFILE), `images.py` (async `image://jf/...` provider + disk cache, maxWidth only), `tasks.py` (thread pool -> Qt signal).
- `models/`: `items.py` (ItemListModel with in-place refresh, LibraryModel/SimilarModel/SearchModel QML types, title match scoring), `details.py`, `series.py`, `home.py`, `sources.py` (version describe/rank/remember), `settings.py` (QSettings ini), `services.py` (globals for QML-instantiated models).
- `player/`: `mpv_runner.py` (external mpv via own `mpv_ipc.py`: `--input-ipc-server` unix socket, request_id replies, events/observers delivered on a separate thread so callbacks can call back into mpv; defaults gpu-next/vulkan/auto-safe/target-colorspace-hint/fullscreen; user `~/.config/jellyfin-tv/mpv.conf` included after defaults, `mpv_extra` last), `playback.py` (resolve -> launch -> report; Up Next in the same mpv: next episode looked up at start, card shown at the outro segment or last 30 s, next item prefetched then `loadfile` replace, `end-file stop` of the replaced file ignored), `reporter.py` (Sessions/Playing start/progress 10s+pause/seek/stop, sent in order off-thread by a one-worker executor), `tracks.py` (own audio/subtitle selection; English subs default), setting `player_ui` (`overlay` default / `native`: stock OSC, no uosc, `script-opts=jftv-overlay=no` so remote.lua only keeps Back→quit); `remote.lua` (overlay remote keys: Left/Right seek 10 s, OK pause, Up playback menu with own audio/subtitle submenus via uosc `open-menu`, plus a Version submenu fed by Python (`jftv-versions` JSON on file-loaded; picking sends `jftv-version <id>`, playback re-resolves that source at the current position in the same mpv and remembers it), Down shows UI, Esc/Back/BS quit), bundled `uosc/` 5.13.0 (LGPL, bin/ dropped; skipped if the user has uosc in ~/.config/mpv/scripts; themed via `script-opts` from the QML accent), `upnext.lua` (OSD card drawn by mpv; Enter plays, Back dismisses; talks to Python via `script-message`).
- Accounts: `session.py` stores `{"active", "accounts": [...]}` (old single-account JSON migrates); Quick Connect = POST QuickConnect/Initiate (token-less header) → poll QuickConnect/Connect → Users/AuthenticateWithQuickConnect. Tests must not touch the real keyring: run logins under `dbus-run-session` (no Secret Service → 0600 file).
- Remote/casting: `api/remote_socket.py` keeps the `/socket` websocket up while signed in (KeepAlive, reconnect) and posts capabilities (`SupportsMediaControl` follows the "Allow remote control" setting); `player/remote_control.py` maps Play/Playstate/GeneralCommand; SyncPlay* messages go to `player/syncplay.py` (GetUtcTime offset, Buffering/Ready, timed Unpause/Pause/Seek via QTimer, local pause/seek become group requests through `PlaybackController.observer`).
- `skip.lua` (segments from `library.segments` or chapter names), `thumbfast.lua` (uosc thumbnail protocol; frames from `api/trickplay.py`, raw BGRA for overlay-add; remote scrubbing in `remote.lua`).
- Gamepad: `gamepad.py` reads SDL2 game controllers through ctypes (no Python dep; SDL2 is in the KDE runtime and the system; `SDL_NO_SIGNAL_HANDLERS` set so Ctrl+C/SIGTERM still work), polled from a QTimer (16 ms with a pad, 500 ms idle for hotplug). Actions: A select, B/View back, X play, Y trailer, Start menu, LB/RB page, D-pad + left stick (hysteresis, dominant axis, held repeat 400/90 ms). `AppController.gamepad_action` sends Qt keys to the window when it is active (or within 15 s after playback ended, since KWin may not refocus), and mpv `keypress` names while playing; otherwise ignored so a pad used in another game doesn't drive the app. Setting `gamepad`. Flatpak needs `--device=input`. Tests use SDL's virtual joystick (`SDL_JoystickAttachVirtual`), which also works for harness runs.
- Trailers: `models/trailers.py` `TrailerPreview` (`app.trailers`: request/release with 0.8 s delay for the muted hero backdrop, `watch` = explicit, immediate, ignores the off setting; `status` ''/loading/ready/none for `currentId`). Source: local trailer (`Items/{id}/LocalTrailers`) else `RemoteTrailers` else `ytsearch1:<title> <year> official trailer` (>10 min rejected) via `api/trailers.py` (yt-dlp, optional; format needs the parentheses, `/` binds looser than `+`), cached per item/URL for 1 h. Details/Show: `HeroTrailer.qml` over the backdrop image loads `TrailerPlayer.qml` (QtMultimedia) through a Loader; `TrailerControls.qml` = full-screen trailer mode (Trailer button, always visible for Movie/Series, dimmed until ready, or key T / gamepad Y; loading screen; Left/Right seek, OK pause, Back closes). Trailer mode switches to `api/trailer_cache.py` (loopback HTTP server, sequential 4 MB range downloads into a temp file, serves player range requests) so seeks don't hit YouTube; background preview streams directly. Separate audio stream joins mid-play when unmuted. Setting `trailer_previews` muted/sound/off (background only). `inhibit.py` `SleepInhibitor` (`app.inhibitor`) holds an org.freedesktop.ScreenSaver inhibit while any `TrailerPlayer` is playing (KDE treats it as blocking suspend; mpv inhibits on its own).
- `ui/`: `Main.qml` StackView routing + Back handling; pages Login/Home/Library/Details/Show/Search/SourcePicker/Settings; components FocusCard/MediaRow/TvButton/SettingRow/OnScreenKeyboard.
- Page models are QML-instantiated types (a QObject returned from a Python slot gets garbage-collected). PySide: a Property's notify must be a signal declared on that same class (base-class signal segfaults).

## Remux / server facts
- MediaSources are `Protocol: File` with virtual paths: always stream `/Videos/{id}/stream?static=true&MediaSourceId=&ApiKey=` (ApiKey only on same-origin URLs).
- `Items/{id}` WITH `Fields` is instant but returns placeholder sources; WITHOUT `Fields` returns the real AIOStreams list (~5 s). Details load with Fields, then fetch sources in the background (`library.sources`).
- Source names are multi-line AIOStreams labels with zero-width chars; resolution label in the name beats stream dimensions; Size often null (parse "4.53 GB", decimal). Season packs read "2.95 / 5.9 GB" or "47.2 MB / 601 MB" (file / pack): first number is the file, shown as "2.95 GB of 5.90 GB". Size/Bitrate fields can be garbage (Size=582, Bitrate=38): fields under 10 MB / 100 kbps or more than 2x off the label lose to the label (incl. "17.6 ᴹᵇᵖˢ").
- `PlaybackInfo` can 500 for some items (e.g. Breaking Bad S1E2) while `Items/{id}` has sources; playback falls back to those.
- Default version: ranked with a Maximum bitrate cap (default 40 Mbps) so 60-80 Mbps remuxes are not picked by default; Details fetches versions in parallel with the item (Play grayed + spinner until they land; pressing it queues the play).
- Audio language `original` resolves to `OriginalLanguage` (movies have it; episodes inherit it from the series in `library.item`); versions without that audio language rank lower.
- Remux has Quick Connect and relays remote-control websocket commands, but no SyncPlay groups (POST SyncPlay/New = 404), no media segments and no trickplay. Those were verified against a throwaway stock Jellyfin 10.11 in podman (localhost:18096).
- AIOStreams can return streams for the wrong show (Steins;Gate 0 S1E18 resolves to "Steins;gate s01E18"); that's addon title matching, the in-player Version menu is the escape hatch.
- Search with ";" misses ("Steins;Gate 0" finds no series, "Steins Gate 0" does).
- Jellyfin only saves resume past ~5% of runtime. Search doesn't fold accents ("Shippūden").

## Packaging / release
- Flatpak `io.github.gettuh.JellyfinTV`: `packaging/flatpak/io.github.gettuh.JellyfinTV.json` on io.qt.PySide.BaseApp 6.11 (KDE 6.11, Python 3.13), mpv built from source as cplayer, pure-Python wheels pinned in `python-deps.json` (regenerate with `gen_python_deps.py`), WebEngine/numpy/LLVM trimmed (~60 MB bundle).
- CI `.github/workflows/jellyfin-tv.yml`: tests on push; unsigned Flatpak validation build on `master` pushes; on `v*` tags: signed OSTree repo deployed to GitHub Pages (https://gettuh.github.io/jellyfin-tv-linux/, `jellyfin-tv.flatpakrepo`) + release bundle. Needs secret `FLATPAK_GPG_PRIVATE_KEY` (`packaging/flatpak/create-signing-key.sh`). Pages is set to Actions with a `v*` tag deploy policy.
- GitHub: `GetTuh/jellyfin-tv-linux`, standalone (not a fork), default branch `master`. Signing key backup in `~/.local/share/jellyfin-tv-signing/` (`private.asc`, `public.asc`, `gnupg/`); restore the secret with `gh secret set FLATPAK_GPG_PRIVATE_KEY -R GetTuh/jellyfin-tv-linux < ~/.local/share/jellyfin-tv-signing/private.asc`. Same key + same Pages URL keeps existing Flatpak installs updating. v0.2.0 was released from the old fork; its bundle is kept locally as `JellyfinTV-0.2.0-x86_64.flatpak` (gitignored).
- Non-Flatpak install: `packaging/install.sh` (venv + `~/.local/bin/jellyfin-tv` + desktop file).
- Steam shortcuts: Steam's runtime env (LD_LIBRARY_PATH/LD_PRELOAD/LANG=C) made Qt abort with "EGL not available"; `steam.py` re-execs once with Steam-runtime paths stripped and locale filled from `systemctl --user show-environment`, keeping Steam's display vars (gamescope).
