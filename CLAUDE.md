# AIOstreamer

Remote-first PySide6/QML client for AIOStreams on Linux TVs and HTPCs, in `aiostreamer/` + `packaging/`. It speaks the Stremio addon protocol of the user's AIOStreams configuration (catalog/meta/stream/subtitles); no Jellyfin server, no Stremio app. Playback runs in an external mpv. Until v0.3.0 this was "Jellyfin TV" (`jellyfin_tv`, `io.github.gettuh.JellyfinTV`, repo `jellyfin-tv-linux`), a Jellyfin/Remux client; v0.4.0 is the AIOStreams rewrite under the new name.

## Rules
- No comments in code. Brief explanations. Match surrounding style.
- Commit checkpoints and push to `origin`.
- Tests must pass before anything deploys; add tests with new logic.
- Verify UI changes with the offscreen harness (below), not by opening windows on the user's desktop.
- Don't hammer AIOStreams: every request goes through `AioClient` and its `JsonCache`; new endpoints get a TTL there.

## Run / test
- Dev: `.venv/bin/python -m aiostreamer --windowed` (venv uses system PySide6 via --system-site-packages; deps in `packaging/requirements.txt`).
- Tests: `QT_QPA_PLATFORM=offscreen .venv/bin/python -m unittest discover -s aiostreamer/tests -t .` plus `.venv/bin/python -m pyflakes aiostreamer`.
- Harness pattern: QT_QPA_PLATFORM=offscreen, XDG_CONFIG_HOME/XDG_CACHE_HOME pointed at a scratch dir, run under `dbus-run-session` (no keyring), register types via `AppController.register_types()`, drive keys with QKeyEvent on the window, `win.grabWindow().save()`, call `openItem` via QMetaObject.invokeMethod. Headless playback: set setting `mpv_extra` to `vo=null\nao=null\nfullscreen=no`. Count AIOStreams requests by wrapping `requests.Session.get`.
- Test instance: throwaway AIOStreams in podman (`podman run -d --name aiostreams-test -p 127.0.0.1:18300:3000 -e BASE_URL=http://localhost:18300 -e SECRET_KEY=<64 hex> ghcr.io/viren070/aiostreams:latest`), user created with `POST /api/v1/user {config, password}` (config needs `presets`, `sortCriteria`, `formatter`): Cinemeta as a `custom` preset for catalog/meta, OpenSubtitles v3 for subtitles, and a tiny local Stremio addon (reachable from the container as `host.containers.internal`) returning a generated test mkv for streams.

## Architecture
- `api/aio.py`: `AioClient(manifest_url, cache)`: URLs `<base>/<resource>/<type>/<id>[/<extra>].json<query>` (ids keep `:`, extras `k=v&k=v` percent-encoded), User-Agent starts with `AIO` so AIOStreams adds `streamData` (parsedFile, size, service, bingeGroup in behaviorHints), at most 4 parallel requests, 429 → readable error. TTLs: manifest 6 h, catalog 30 min, search 1 h, meta 24 h (6 h with `hasScheduledVideos`), stream 15 min, subtitles 6 h. Error metas (`aiostreamserror*`) and non-playable streams (error/statistic/p2p/no url) are dropped. `resolve_manifest` = `GET /api/v1/user` with Basic auth (UUID or alias + password) → `/stremio/<uuid>/<encryptedPassword>/manifest.json`.
- `api/cache.py`: `JsonCache` per account (`~/.cache/aiostreamer/aio/<key>/`): memory LRU + disk JSON, `get(key, ttl, fetch)` returns fresh hits without network, serves stale on errors, shares one fetch between concurrent callers; `peek` for instant paint; pruned after 30 days unused.
- `api/meta.py`: Stremio meta → app items (`id, type Movie/Series/Episode, stremioType, name, poster, background, logo, year, overview, genres, rating, runtime (s), trailers (yt ids), seriesId, season, episode`). `anime` counts as Series; unknown types with seasonal videos too, unless `behaviorHints.defaultVideoId` is set (Movie, streams fetched for `videoId`, e.g. AIOStreams library movies `<id>:0`). Library catalog previews carry no videos, so DetailsPage replaces itself with ShowPage once the meta turns out to be a series. Catalog titles ("Popular" + type label), `browsable` (only a required genre with options is allowed), `home_extra`, `searchable`.
- `api/history.py`: `WatchState` per account (`~/.config/aiostreamer/state/<key>.json`): progress (kept from 60 s and 2 %), watched at 90 %, new progress un-watches, per-show last episode (only moved by real progress), favorites ("My List"), slim item copies for rows.
- `api/library.py`: when the AIOStreams manifest has no browsable movie/series catalog, public Cinemeta (`AioClient` with `cinemeta:` cache prefix) fills those catalogs (listed first) and search; meta for `tt` ids goes to Cinemeta when the manifest has no meta resource for that type/prefix (checked with `aio.supports`). Catalogs/home rows, paged catalog with dedupe (`skip` = metas received), search across searchable catalogs of a type, item lookup (episodes via their series meta; `known()` remembers type/series of every item seen, then history, then `tt…:S:E`), Next Up (after the last finished episode, skipping specials, watched and unaired; hidden while one is in progress), series next up, next episode, streams, subtitles (`filename`/`videoSize`/`videoHash` extras + stream subtitles), trailers.
- `api/session.py`: accounts `{key, manifest, name, instance, user}` in keyring (`aiostreamer`/`aiostreams`) or 0600 `accounts.json`; restore works offline from a cached manifest. `api/images.py`: `image://img/<kind>/<base64url>[/<base64url>…]` async provider with disk cache; later URLs are fallbacks tried when one fails (metahub has no episode stills past season 1 for many anime, e.g. Naruto/One Piece). `api/tasks.py`: thread pool → Qt signal.
- `models/`: `items.py` (ItemListModel with optional `peek` for cached first paint, in-place refresh, user-data roles read live from history; LibraryModel = catalog + genre cycling; SearchModel), `home.py` (local rows + one row per catalog + Browse row of catalogs), `details.py` (streams fetched in parallel with the meta when the type is known; Play waits for them; `refreshSources` bypasses the cache), `series.py` (seasons/episodes from one meta), `sources.py` (describe from parsedFile, else guessed from filename/bingeGroup/description/name, since some instances (ElfHosted) never send `streamData`; ids without streamData are `file:<filename>|<size>` because playback URLs change per fetch; default = first stream within the resolution/bitrate caps, AIOStreams order otherwise kept; explicit choices remembered per item and per series by filename then bingeGroup), `settings.py`, `services.py` (globals for QML-instantiated models), `trailers.py`.
- `player/`: `mpv_runner.py` (external mpv via own `mpv_ipc.py`; defaults gpu-next/vulkan/auto-safe/target-colorspace-hint/fullscreen; user `~/.config/aiostreamer/mpv.conf` after defaults, `mpv_extra` last), `playback.py` (resolve item → streams → pick → launch; `http-header-fields` from `behaviorHints.proxyHeaders`, reset on every swap; progress recorded to history every 10 s, on pause, swap and exit; Up Next in the same mpv in the last 30 s, next episode prefers the current stream's bingeGroup; audio setting `original` (default) maps the meta `country` to a language via `tracks.country_language`, looked up only when a file has 2+ audio tracks (`Library.country`: item/series meta, or a Cinemeta name+year search for library items), else a track titled Original, else the file default; addon subtitles only when no internal track matches and the audio isn't already in a subtitle language; in-player Version menu via `remote.lua` `aios-versions`/`aios-version`), `tracks.py`, `remote.lua`, bundled `uosc/` 5.13.0 (LGPL), `upnext.lua`, `skip.lua` (chapter names only now).
- Gamepad: `gamepad.py` reads SDL2 game controllers through ctypes, polled from a QTimer; `AppController.gamepad_action` sends Qt keys to the window when active (or within 15 s after playback), mpv `keypress` names while playing. Flatpak needs `--device=input`. Tests use SDL's virtual joystick.
- Trailers: `models/trailers.py` `TrailerPreview` (request/release with 0.8 s delay, `watch` explicit). Source: meta `trailerStreams`/`trailers` YouTube ids else `ytsearch1:<title> <year> official trailer` via `api/trailers.py` (yt-dlp, optional). `HeroTrailer.qml`/`TrailerPlayer.qml`/`TrailerControls.qml`; full-screen mode uses `api/trailer_cache.py`. `inhibit.py` holds a ScreenSaver inhibit while a trailer plays.
- `ui/`: `Main.qml` StackView routing (`Catalog` entries → LibraryPage, `Series` → ShowPage, else DetailsPage) + Back handling; pages Login/Home/Library/Details/Show/Search/SourcePicker/Settings.
- Page models are QML-instantiated types (a QObject returned from a Python slot gets garbage-collected). PySide: a Property's notify must be a signal declared on that same class (base-class signal segfaults).

## AIOStreams facts (2.36)
- Its own "app" and Jellyfin-app support are a Jellyfin-compatible API on the instance; this client deliberately uses only the Stremio protocol, so watch state is local.
- ShowPage has a Version button that loads the next-up episode's streams only when pressed; the choice is remembered and used by Play.
- `streamData` is only sent when the User-Agent starts with `AIO` (or the instance forces it). `streamData.id` is index-based (`<addon>-<n>`), not stable across fetches: remember streams by filename/bingeGroup.
- Cinemeta through AIOStreams: catalogs `top` (genre/search/skip), `year` (genre required, options are years), `imdbRating`, plus `last-videos`/`calendar-videos` (required non-genre extras, skipped). Pages are ~50 metas; meta includes `videos` with season/episode (or `number`), thumbnails, `trailerStreams`, metahub images (posters webp).
- P2P streams have no `url` (infoHash only) and are not playable here; AIOStreams' own app doesn't play them either.

## Packaging / release
- Flatpak `io.github.gettuh.AIOstreamer`: `packaging/flatpak/io.github.gettuh.AIOstreamer.json` on io.qt.PySide.BaseApp 6.11 (KDE 6.11, Python 3.13), mpv built from source as cplayer, pure-Python wheels pinned in `python-deps.json` (regenerate with `gen_python_deps.py`), WebEngine/numpy/LLVM trimmed (~60 MB bundle).
- CI `.github/workflows/aiostreamer.yml`: tests on push; unsigned Flatpak validation build on `master` pushes; on `v*` tags: signed OSTree repo deployed to GitHub Pages (https://gettuh.github.io/AIOstreamer-linux/, `aiostreamer.flatpakrepo`) + release bundle. Needs secret `FLATPAK_GPG_PRIVATE_KEY` (`packaging/flatpak/create-signing-key.sh`). Pages is set to Actions with a `v*` tag deploy policy.
- GitHub: `GetTuh/AIOstreamer-linux`, standalone (not a fork), default branch `master`. Signing key backup in `~/.local/share/jellyfin-tv-signing/` (`private.asc`, `public.asc`, `gnupg/`); restore the secret with `gh secret set FLATPAK_GPG_PRIVATE_KEY -R GetTuh/AIOstreamer-linux < ~/.local/share/jellyfin-tv-signing/private.asc`. Same key + same Pages URL keeps existing Flatpak installs updating.
- Non-Flatpak install: `packaging/install.sh` (venv + `~/.local/bin/aiostreamer` + desktop file).
- Steam shortcuts: Steam's runtime env (LD_LIBRARY_PATH/LD_PRELOAD/LANG=C) made Qt abort with "EGL not available"; `steam.py` re-execs once with Steam-runtime paths stripped and locale filled from `systemctl --user show-environment`, keeping Steam's display vars (gamescope).
